# 第 9 步：从距离到奖励

实验脚本：[step9_reward.py](step9_reward.py)

```bash
pixi run python docs/learn/step9_reward.py
```

前面几步得到的是一个距离 d。训练需要的是奖励 r。这一步看 d 到 r 的映射怎样影响 GRPO 的学习信号。距离 d 统一采用第 8 步建议的"质心 + RMS 半径 + 4 个水平角"，数值取自第 8 步的实测。

## 1. GRPO 实际用的是优势值，不是奖励本身

本项目配置 `rollout.n: 4`、`norm_adv_by_std_in_grpo: true`：同一个提示词生成 4 个回答，每个回答的**优势值**（advantage，决定这个回答的 token 被鼓励还是被抑制、力度多大）是

```
Aᵢ = (rᵢ − 组内均值) / (组内标准差 + 10⁻⁶)
```

由此有一个直接推论：**对奖励做正的线性变换 r → a·r + b（a > 0），优势值完全不变。** 均值跟着变换，标准差只乘 a，相除后抵消。所以奖励的绝对数值没有意义，只有同一组回答之间的**相对差距**有意义。

## 2. 不同质量的回答对应的奖励

```
回答                       d       exp(-d)（现状）   1 - d（线性）   exp(-d/0.1)
完美（噪声底）            0.0250        0.9753          0.9750         0.7788
删掉一条桌腿              0.0475        0.9536          0.9525         0.6219
长边拉长 30%              0.0534        0.9480          0.9466         0.5863
上下颠倒                  0.2327        0.7924          0.7673         0.0976
完全不同的物体（杯子）     0.4273        0.6523          0.5727         0.0139
完全不同的物体（石柱）     0.7556        0.4697          0.2444         0.0005
```

"完全不同的物体"是把杯子、石柱的网格当作生成结果，去和书桌比较，代表"能执行但形状完全错"的回答。脚本执行失败的回答，奖励固定为 0。

两点观察：

- **exp(−d) 在 d 较小时几乎就是线性的**：exp(−d) ≈ 1 − d，前三行两列的数值几乎相同。好的回答全挤在 0.95 到 0.975 之间，但按第 1 节的推论，这种"挤"本身不影响训练。
- **温度 τ**：exp(−d/τ) 里的 τ 决定曲线在哪个距离范围内变化明显。τ = 0.1 时，好回答落在 0.59 到 0.78，上下颠倒只剩 0.10，完全错的物体接近 0。

## 3. 三种典型的组

### 组 A：全部成功，质量参差

```
d = [0.025, 0.0475, 0.2327, 0.4273]
exp(-d)（现状）   优势 [ 0.87  0.73 -0.34 -1.26]
1 - d（线性）     优势 [ 0.84  0.72 -0.26 -1.30]
exp(-d/0.1)       优势 [ 1.06  0.64 -0.74 -0.96]
```

三种映射给出的排序相同，优势值也接近。exp(−d) 和 1 − d 几乎一样，印证了第 1、2 节的结论。

### 组 B：一个失败，三个形状都不错

```
d = [失败, 0.025, 0.0475, 0.0534]
exp(-d)（现状）   优势 [-1.50  0.53  0.49  0.48]
1 - d（线性）     优势 [-1.50  0.54  0.49  0.48]
exp(-d/0.1)       优势 [-1.45  0.83  0.37  0.26]
```

失败回答的奖励是 0，离其他回答（约 0.95）很远，组内标准差几乎全由它贡献。于是用现状的 exp(−d) 时，三个成功回答的优势值都在 0.5 左右，完美的和少一条腿的几乎没有区别。这一组传递的信号只剩下"能执行比不能执行好"。

τ = 0.1 时，成功回答的奖励拉开了距离，失败和成功之间的差距相对变小，完美回答的优势值（0.83）明显高于少一条腿的（0.37）。

训练初期，很多回答会执行失败，这种组会很常见。

### 组 C：全部成功，差别只是采样噪声

```
d = [0.02500, 0.02506, 0.02494, 0.02503]
exp(-d)（现状）   优势 [ 0.14 -1.00  1.29 -0.43]
```

四个回答的形状实际上同样好，d 只在第 6 步测得的采样噪声范围内波动（标准差约万分之一）。但除以组内标准差之后，这点噪声被放大成了 ±1 量级的优势值，和组 A 里真正的质量差距一样大。

这是"除以组内标准差"这一做法本身的性质，和映射方式无关：组内差距越小，放大得越厉害。训练后期，当模型稳定地建出几乎正确的形状时，会出现这种组，学习信号会被噪声主导。缓解办法包括关掉 `norm_adv_by_std_in_grpo`（只减均值，不除标准差），或者把差距小于噪声底的奖励视为相同。按目前"形状大致正确"的目标，训练很可能还走不到这个阶段，先记下，不处理。

## 4. 映射的取舍

映射方式实际上决定了两件事：

1. **"能执行但形状完全错"值多少分**：现状 exp(−d) 下，形状完全错的物体也能拿 0.47 到 0.65 分，大约是完美回答的一半，相当于"只要能执行就有一半的分"。τ = 0.1 时，形状完全错的回答接近 0 分，和执行失败没有区别。
2. **好回答之间能否拉开差距**：主要在组 B 这种"有失败也有成功"的组里起作用。

两者之间有一个取舍。训练初期，如果模型大部分回答都执行失败，"能执行"本身就值得奖励，这时 τ 大一些（或者就用现状的 exp(−d)）更好；如果模型已经基本能执行，τ 小一些能更好地区分形状好坏。

τ 应该根据**初始模型实际回答的距离分布**来定：先用初始模型对一批训练样本生成回答，统计执行成功率和 d 的分布，再选 τ。不需要现在就定死。

## 和奖励的关系

1. 奖励只有组内相对差距有意义，正的线性变换不影响训练。exp(−d) 的数值挤在 0.95 附近本身不是问题。
2. 执行失败得 0 分，会让"有失败的组"里成功回答之间的形状差异几乎消失。温度 τ 可以缓解这个问题。
3. 组内标准化会放大噪声级别的差距。训练后期才会遇到，目前先记下。
4. τ 的取值等初始模型的回答分布出来之后再定。

## 检验问题

如果所有成功回答的奖励都挤在 0.9 到 0.95 之间，组内标准化之后会发生什么？

## 解答

如果组里没有失败的回答，什么问题也不会发生。标准化会把组内差距拉伸到标准差为 1 的尺度，挤在 0.9 到 0.95 和分布在 0 到 1 效果相同（组 A）。

需要担心的是另外两种情况：

- 组里有失败的回答（组 B）：0 分和 0.9 分的差距主导了标准差，成功回答之间的差距被压扁。
- 组内差距完全来自采样噪声（组 C）：标准化把噪声放大成和真实差距一样大的信号。

所以真正要看的不是奖励挤不挤，而是组内差距是由什么造成的。
