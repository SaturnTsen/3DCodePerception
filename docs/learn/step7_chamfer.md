# 第 7 步：Chamfer 距离的细节

实验脚本：[step7_chamfer.py](step7_chamfer.py)

```bash
pixi run python docs/learn/step7_chamfer.py
```

第 6 步把两份网格各变成了 4096 个点。这一步看 Chamfer 距离怎样比较这两份点云：它对哪种错误敏感，对哪种错误不敏感。

## 1. 定义：两个方向的平均最近距离

设目标点云为 T，生成结果的点云为 P。对每个点，找另一份点云里离它最近的点，记下距离：

```
目标→生成 = 对 T 中每个点 t，求 min_p ‖t − p‖，再取平均
生成→目标 = 对 P 中每个点 p，求 min_t ‖p − t‖，再取平均
```

`rl/geometry.py` 里的奖励距离是两个方向取平均，再除以目标包围盒对角线：

```
d = (目标→生成 + 生成→目标) / 2 / 对角线
奖励 = exp(−d)
```

两个方向分别惩罚不同的错误：

| 方向 | 什么时候变大 | 惩罚的错误 |
|---|---|---|
| 目标→生成 | 目标上有一块，生成结果附近没有 | **缺失**的部件 |
| 生成→目标 | 生成结果多出一块，目标附近没有 | **多余**的部件 |

只用一个方向是不够的。只看"生成→目标"，模型只建一个桌面也能拿满分，因为桌面上的每个点在目标里都有对应；只看"目标→生成"，模型建一个充满整个包围盒的大方块也能得高分，因为目标的每个点附近都有方块表面。两个方向合起来，才同时约束"不缺"和"不多"。

## 2. 实验：对书桌做各种破坏

### 表中各列的定义

记号：

- T = {t₁, …, t_N}：在**目标**书桌表面上撒的 N = 4096 个点（种子 42）。
- P = {p₁, …, p_N}：在**被破坏后的书桌**表面上撒的 N = 4096 个点（种子 43）。被破坏的书桌扮演"模型生成结果"的角色。
- D：目标书桌包围盒的对角线长度，1.578 米。所有距离都除以 D，变成"对角线的百分之几"，这样不同大小的物体可以用同一把尺子量。

| 列名 | 公式 | 含义 |
|---|---|---|
| 目标→生成 | (1/N) Σᵢ min_j ‖tᵢ − pⱼ‖ / D | 目标上每个点到生成结果最近点的距离，取平均 |
| 生成→目标 | (1/N) Σⱼ min_i ‖pⱼ − tᵢ‖ / D | 生成结果上每个点到目标最近点的距离，取平均 |
| d（奖励） | (目标→生成 + 生成→目标) / 2 | 两个方向的平均，就是 `rl/geometry.py` 实际用的距离，奖励 = exp(−d) |
| 平方距离版 | ½ [ (1/N) Σᵢ (min_j ‖tᵢ − pⱼ‖ / D)² + (1/N) Σⱼ (min_i ‖pⱼ − tᵢ‖ / D)² ] | 先把每个最近距离（已除以 D）平方，再按同样方式平均。benchmark 用的是这种 |
 
"平方距离版"的单位是 D²，和前三列不是一个量纲，所以数值小得多（0.0001 对 0.0073），不能和前三列直接比较，只能和本列第一行比较。

**读一行的例子**："删掉一条桌腿"这一行，目标→生成 = 0.0161，意思是目标书桌上的点，平均离被删腿的书桌最近点有 1.61% 对角线，约 2.5 厘米。其中大部分点的距离仍然只有噪声底水平（约 1 厘米），被拉高的是落在那条被删的腿上的 3.6% 的点：它们只能连到很远的桌面底部或其他腿上。

### 各行的破坏方式

| 行 | 具体操作 |
|---|---|
| 完全相同 | 不做任何改动，只换一个种子撒点 |
| 删掉一条桌腿 | 删掉 x > 0、y > 0 那个角上的桌腿的全部三角形 |
| 桌面上多一个 20cm 方块 | 在桌面正中央上方加一个边长 20 厘米的立方体，底面贴着桌面 |
| 远处多一个 2cm 小方块 | 在书桌正上方约 1.1 米处加一个边长 2 厘米的立方体 |
| 整体平移 | 所有顶点沿 x 方向移动 2 厘米或 10 厘米 |
| 整体放大 10% | 所有顶点坐标乘以 1.1 |
| 绕竖直轴转 | 绕 z 轴转 90° 或 180° |

### 结果

书桌包围盒对角线 1.578 米，一条桌腿占总表面积的 3.6%：

```
破坏方式                   目标→生成  生成→目标  d（奖励）  平方距离版
完全相同（噪声底）           0.0073    0.0073    0.0073     0.0001
删掉一条桌腿                0.0161    0.0074    0.0118     0.0014
桌面上多一个 20cm 方块       0.0076    0.0136    0.0106     0.0004
远处多一个 2cm 小方块        0.0073    0.0081    0.0077     0.0003
整体平移 2cm                0.0080    0.0082    0.0081     0.0001
整体平移 10cm               0.0176    0.0179    0.0177     0.0007
整体放大 10%                0.0180    0.0208    0.0194     0.0005
绕竖直轴转 90°              0.0522    0.0535    0.0529     0.0067
绕竖直轴转 180°             0.0072    0.0072    0.0072     0.0001
```

#### Chamfer的两个匹配方向，各司其职

- **删掉一条桌腿**：只有"目标→生成"变大（0.0073 → 0.0161）。目标上那条腿的点在生成结果里找不到对应，只能连到桌面底部或别的腿上。"生成→目标"不变，因为剩下的部分在目标里都有对应。
- **多一个方块**：反过来，只有"生成→目标"变大（0.0073 → 0.0136）。

### Chamfer 距离的缺陷

每个点的权重按面积分配，而不是按"重要性"

一条桌腿只占总表面积的 3.6%，所以只分到约 3.6% 的采样点。删掉它，d 只从 0.0073 升到 0.0118。从人的角度看，三条腿的桌子是一个明显的结构错误；但对 Chamfer 距离来说，它只是丢了一小块面积。

****：Chamfer 距离增加得少，并不代表这个部位不重要。

把目标上的 4096 个点分成两组，"落在被删桌腿上的点"和"其余的点"，平均值可以严格拆成两组的加权和：

```
目标→生成 = 桌腿点占比 × 桌腿点的平均距离 + 其余点占比 × 其余点的平均距离
```

实测（距离已除以对角线 D = 1.578 米）：

| | 桌腿点（159 个，占 3.88%） | 其余点（3937 个，占 96.12%） | 加权和 |
|---|---|---|---|
| 完全相同 | 0.0071（1.1 厘米） | 0.0073（1.2 厘米） | 0.0073 |
| 删掉这条腿 | **0.2352（37.1 厘米）** | 0.0072（1.1 厘米） | 0.0161 |

验算：0.0388 × 0.2352 + 0.9612 × 0.0072 = 0.0161，和表中"目标→生成"一致。

删腿之后，其余点的距离没有变化，全部增量都来自桌腿上的 159 个点：它们的平均距离从 1.1 厘米变成 37.1 厘米，增大了 30 多倍，其中最远的点离最近表面 65 厘米。局部误差非常大，只是取平均时这些点只占 3.88% 的权重，被其余 96.12% 的点稀释了。

（桌腿的面积占比是 3.6%，这次采样实际落在腿上的点占 3.88%，两者的差别来自采样的随机性。）

**稀释的来源是"按面积均匀撒点"加"取平均"。** 点数趋于无穷时，"目标→生成"收敛到一个面积积分：

```
目标→生成 → (1/|M|) ∫_M dist(x, 生成结果) dσ(x)
```

其中 σ 是面积测度。每个部位的权重就是它的面积占比，这是由撒点方式决定的。要改变权重，有两个入手点：

| 入手点 | 做法 | 效果和代价 |
|---|---|---|
| 换撒点的权重 | 不按面积，而是按部件分配点数，例如每个部件分到相同数量的点 | 桌面和四条腿各占 20% 时，按上表的实测分组均值计算，删一条腿的"目标→生成"是 0.2 × 0.2352 + 0.8 × 0.0072 ≈ 0.053，而不是 0.0161。代价是需要定义"部件"，并且螺丝之类的小零件会被同等放大 |
| 换汇总方式 | 仍按面积撒点，但不取普通平均，例如取平方后平均 | 放大少数离得远的点（上文：1.6 倍变 14 倍）。代价是离群杂物也被放大 |

按面积撒点的好处是定义简单，而且结果与三角形怎么划分无关（第 6 步）。它是一种权重的选择，不是唯一正确的选择。

Chamfer 距离衡量的是"出错的面积 × 错得多远"。一个部位重不重要，取决于它在结构和功能上的作用，和面积没有关系。

这就是 Chamfer 距离对**细小结构**不敏感的原因：桌腿、栏杆、把手、植物的细枝，这些结构在视觉和功能上很重要，面积却很小。大面积的平面（如桌面占 85.7%）主导了距离。

**远处的小方块**也是同样的道理：2 厘米的方块离桌子 1 米多远，但只占 0.1% 的面积，d 几乎没变（0.0077）。

### 平方距离对离群点更敏感

"平方距离版"先把每个最近距离平方，再取平均。距离大的点被平方放大，距离小的点被平方缩小。对照几行：

| 破坏方式 | d 相对噪声底 | 平方距离版相对噪声底 |
|---|---|---|
| 远处 2cm 小方块 | 1.05 倍 | 3 倍 |
| 删掉一条桌腿 | 1.6 倍 | 14 倍 |
| 转 90° | 7 倍 | 67 倍 |

平方距离会放大"少数点离得很远"的情况。好处是缺一条腿这种局部错误更显眼；坏处是一小块离群的杂物也会被放大。benchmark 的 `shape_chamfer.py` 用的是平方距离，本项目的奖励用的是普通距离。

### 两个方向"相加"还是"平均"

benchmark 把两个方向相加，本项目取平均，两者只差一个固定的 2 倍。第 9 步会讲到，GRPO 在组内标准化奖励，乘一个常数不影响训练；但在套上 exp(−d) 之前乘 2，会改变映射曲线的形状。

## 3. 和位置、尺度、朝向有关的几行

| 破坏方式 | d | 能从参考图看出来吗（第 5 步） |
|---|---|---|
| 删掉一条桌腿 | 0.0118 | 能 |
| 整体平移 10cm | 0.0177 | 不能 |
| 整体放大 10% | 0.0194 | 不能 |
| 绕竖直轴转 90° | 0.0529 | 不能 |

这张表直接暴露了当前奖励的问题：**图里看不出来的错误，扣分比图里看得出来的错误还多。** 平移 10 厘米、放大 10% 都比少一条腿扣分多；转 90° 的扣分是少一条腿的 10 倍以上（扣掉噪声底后，0.0456 对 0.0045）。

转 180° 的距离和噪声底一样，因为书桌前后左右对称，转 180° 后和原来完全重合。

如果不先消除这些差异，奖励的大部分变化会来自模型无法从图片中获得的信息，真正的形状差异反而被淹没。这是第 8 步要先做对齐和归一化的直接原因。

## 和奖励的关系

1. 两个方向缺一不可："目标→生成"惩罚缺失，"生成→目标"惩罚多余。
2. 每个点的权重按面积分配，细小结构（桌腿、栏杆）影响很小，但这不代表它们不重要。这是 Chamfer 距离固有的盲区，增加点数没有用（比例不变），只能换别的指标部分缓解。
3. 平方距离放大远处的错误，普通距离更平稳。
4. 不做对齐时，位置、尺度、水平朝向这些图里看不出来的差异，扣分远多于真正的形状错误。

## 检验问题

平移 10 厘米和删掉一条桌腿，哪个扣分更多？这个结果合理吗？

## 解答

平移 10 厘米扣分更多（d = 0.0177，删桌腿是 0.0118）。这不合理：参考图看不出物体的位置（第 5 步），模型无从知道该放在哪里；而少一条腿是图里一眼就能看出的错误。奖励应该反过来，对少腿扣分，对平移不扣分。

解决办法是第 8 步的对齐：比较前把两份几何的中心对齐，平移的影响就消失了；删掉一条腿几乎不改变包围盒中心，所以它的扣分会保留下来。
