# 第 6 步：表面采样，从网格到点云

实验脚本：[step6_sampling.py](step6_sampling.py)

```bash
pixi run python docs/learn/step6_sampling.py
```

第 1 步说过：两份网格的顶点和三角形无法逐个对应，要改成比较**表面**。做法是在两个表面上各撒一批点，变成两份**点云**（point cloud，即一组三维坐标点，彼此之间没有连接关系），再比较点云。这一步讲怎么撒点，以及撒点本身会给奖励带来多大的误差。

## 1. 按面积均匀撒点

`rl/geometry.py` 的 `sample_surface` 分两步撒点：

1. **按面积挑三角形**：每个点先随机挑一个三角形，挑中的概率和三角形面积成正比。大三角形挑中的次数多，小三角形少。
2. **在三角形内部均匀取一点**：用两个随机数 u、v，按重心坐标（barycentric coordinates，即把三角形内的点写成三个顶点的加权平均，权重非负且和为 1）组合出一个点：

   ```
   点 = (1 − √u)·A + √u·(1 − v)·B + √u·v·C
   ```

   这里取 √u 而不是 u，是因为离顶点 A 越远，三角形的截面越宽。用 √u 正好让点在整个三角形里均匀分布；直接用 u 会让点在 A 附近扎堆。

两步合起来的效果是：**表面上每一块相同面积的区域，分到的点数期望相同**，和网格怎样划分三角形无关。实验第 1 部分验证了这一点：书桌桌面上表面占总面积的 40.2%，4096 个点里有 40.6% 落在上表面附近。

这一点很重要：第 1 步提到，平的桌面只用 2 个三角形表示，弯曲的桌腿用了上千个三角形。如果按"每个三角形撒一个点"，桌腿会被过度代表。按面积撒点之后，只有表面本身的大小起作用。

## 2. 撒点带来的误差：噪声底

撒点是随机的，两次撒出的点不会完全重合。所以**即使两个形状完全相同，Chamfer 距离也不是 0**。这个"形状完全相同时的距离"叫作**噪声底**（noise floor），它是奖励能分辨的最小差异的参照。

### 固定种子消除不了噪声底

奖励配置里固定了随机种子 `seed: 42`，目标和生成结果都用这个种子撒点。实验第 2 部分说明，这并不能消除噪声底：

```
三角形数 1020 → 4080
点数  1024：原网格对自己 d=0.0000   原网格对细分网格 d=0.0137
点数  4096：原网格对自己 d=0.0000   原网格对细分网格 d=0.0074
```

"细分网格"把每个三角形沿边的中点切成 4 个，形状完全不变，只是三角形划分不同。网格完全相同时，同一个种子撒出的点完全一样，距离是 0。但只要三角形划分不同，同一个种子撒出的就是完全不同的一组点，距离和用不同种子撒点几乎一样（0.0074 对 0.0073）。

模型生成的网格和目标网格的三角形划分必然不同（第 1 步的结论），所以固定种子的作用只是让同一个回答每次算出的奖励相同（可复现），不能降低噪声底。

### 噪声底随点数的变化

实验第 3 部分对 5 个物体，用不同种子撒点，测量噪声底（距离已按目标包围盒对角线归一化，和 `rl/reward.py` 一致）：

```
物体                          N=1024    N=4096    N=8192   N=32768
SimpleDeskFactory           0.0136    0.0073    0.0052    0.0026
CupFactory                  0.0199    0.0116    0.0085    0.0043
LiteDoorFactory             0.0125    0.0065    0.0047    0.0024
SpiralStaircaseFactory      0.0117    0.0061    0.0044    0.0023
MushroomFactory             0.0157    0.0095    0.0074    0.0045
```

点数每增加到 4 倍，噪声底大约减半，也就是和 1/√N 成正比。原因是：点越密，相邻点之间的平均间距越小，而一个点到另一份点云最近点的距离，大致就是这个间距的量级。表面是二维的，点数增加到 4 倍，间距缩小一半。

当前配置是 `samples: 4096`，噪声底约为对角线长度的 0.6% 到 1.2%。

### 噪声底主要是一个固定偏差，波动很小

实验第 4 部分对书桌用 20 个不同种子重复测量：

```
点数  1024：均值 0.01374   标准差 0.00022
点数  4096：均值 0.00729   标准差 0.00006
点数  8192：均值 0.00515   标准差 0.00003
```

标准差只有均值的 1% 左右。也就是说，噪声底几乎是一个**固定的偏差**：完美的回答总会得到约 0.0073 的距离，而不是 0；但这个数值本身很稳定，不会忽大忽小。

这个结论修正了学习路径里原来的设想。原来以为噪声底会让奖励随机抖动，实际上它主要是一个偏差，抖动很小。

### 噪声底的理论值，以及它随物体变化

在表面上按面积均匀撒 N 个点，点的面密度是 λ = N / |M|（|M| 是表面积）。局部把曲面看成平面，一个固定点到最近采样点的距离 r 满足 P(r > s) ≈ exp(−λπs²)，于是

```
E[r] = ∫₀^∞ exp(−λπs²) ds = 1 / (2√λ) = ½ √(|M| / N)
```

奖励里的距离是普通距离（不平方），两个方向都是 N = 4096，再除以对角线 D，所以

```
噪声底 ≈ ½ √(|M| / N) / D = ½ √(|M| / D²) / √N
```

它取决于 **|M| / D²**，也就是"表面积相对于包围盒大小有多大"，这是一个随物体形状变化的量。和实测对照：

| 物体 | |M| / D² | 公式 | 实测 | 完美回答的奖励 |
|---|---|---|---|---|
| 书桌 | 0.88 | 0.0073 | 0.0073 | 0.9927 |
| 门 | 0.84 | 0.0072 | 0.0065 | 0.9935 |
| 螺旋楼梯 | 0.86 | 0.0072 | 0.0061 | 0.9939 |
| 杯子 | 2.43 | 0.0122 | 0.0116 | 0.9885 |
| 蘑菇 | 10.66 | 0.0255 | 0.0095 | 0.9905 |

前四个吻合得很好。蘑菇偏差很大，原因是它有大量层层叠叠、彼此很近的曲面（菌褶）：一个点的最近邻常常落在相邻的另一层曲面上，比"局部是一张平面"的假设近得多。杯子有内外两层壁，也有轻微的同类效应。

**结论：噪声底是每个目标各自的一个常数，不同物体之间不同。** 完美建出的杯子只能拿到 0.9885，比把书桌平移 1% 对角线（d = 0.0110，奖励 0.9891）还低。所以奖励的绝对值不能跨物体直接比较。

它对不同用途的影响不同：

| 用途 | 是否受影响 | 原因 |
|---|---|---|
| GRPO 组内比较 | 基本不受影响 | 同一组回答对应同一个目标、同样的点数，噪声底对整组相同，组内标准化会把它减掉 |
| 训练曲线上的平均奖励、验证集平均分 | 受影响 | 平均值里混入了每个物体不同的噪声底，批次里物体组成一变，平均值就跟着变 |
| 两个模型在同一组物体上比较 | 影响较小 | 每个物体的噪声底对两个模型相同，但由于距离不是简单相加（下一节），不能完全抵消 |

可以消除它的办法：

1. **减去每个目标的噪声底**：数据准备时，对每个目标用两个不同种子撒点，算一次自身距离，存下来作为基线。代价很小，但只是近似，因为距离不是简单相加。
2. **改用点到网格的距离**：在一边撒点，直接计算这些点到另一边**三角形表面**的精确距离，而不是到另一边采样点的距离。形状相同时距离严格为 0，噪声底消失。代价是要做点到三角形的距离查询，对蘑菇这种几百万个三角形的网格更慢。
3. **增加点数**：噪声底按 1/√N 下降，但永远不为 0，物体之间的差别仍然存在。

选哪种，留到第 10 步一起决定。

## 3. 噪声底会"压缩"小的形状差异

实验第 5 部分给书桌制造两种真实的差异，分别用"同一组采样点"（只看形状差异本身）和"不同种子"（实际奖励的情况）计算距离：

```
整体上移 1% 对角线      同一组采样点 d=0.0092   不同种子 d=0.0110  奖励 exp(-d)=0.9891
整体放大 5%            同一组采样点 d=0.0124   不同种子 d=0.0128  奖励 exp(-d)=0.9873
```

上移 1% 对角线，形状差异本身对应的距离是 0.0092；加上采样误差后是 0.0110，只比完美回答的 0.0073 多出 0.0037。距离不是简单相加的：每个点只看离它最近的点，形状差异小于点间距时，一部分差异会被"淹没"在点间距里。

所以，小于噪声底量级的形状差异，在奖励里体现得很弱。因为噪声底很稳定，这些差异仍然能被分辨，但分数差距很小。

## 和奖励的关系

1. **撒点按面积进行**，奖励只取决于表面本身，和三角形划分无关。
2. **固定种子只保证可复现**，不能降低噪声底。
3. **噪声底在 4096 个点时约为对角线的 0.6% 到 1.2%**，几乎是固定偏差，波动很小。小于这个量级的形状差异，奖励只能给出很小的区分。
4. 还要注意距离和奖励的数值：上面这些情况的奖励 exp(−d) 全都在 0.987 到 0.993 之间。这个映射是否有足够的区分度，第 9 步专门讨论。

## 检验问题

把点数从 4096 提高到 32768，噪声底能降到约三分之一。代价是什么？什么情况下才值得这样做？

## 解答

**代价**：奖励计算变慢。实测单个回答的耗时：

| 物体 | 点数 | 两次撒点 | 最近邻比较 |
|---|---|---|---|
| 书桌（1020 个三角形） | 4096 | 0.001 秒 | 0.005 秒 |
| 书桌 | 32768 | 0.007 秒 | 0.052 秒 |
| 蘑菇（338 万个三角形） | 4096 | 1.09 秒 | 0.006 秒 |
| 蘑菇 | 32768 | 1.11 秒 | 0.054 秒 |

最近邻比较的耗时随点数增长约 10 倍，但也只有 0.05 秒。大网格的撒点耗时主要花在计算三角形面积上，和点数关系不大。相比启动 Blender 和执行脚本的几秒到几十秒，这些都很小。所以提高点数的计算代价不大。

**什么时候值得**：只有当训练后期，好回答之间的形状差异已经小到和噪声底同一量级时，提高点数才有意义。训练初期，回答之间的差异是"桌腿有没有""形状对不对"这种量级，距离远大于噪声底，4096 个点足够区分。所以当前配置暂时不需要改动。如果后期需要更细的区分，提高点数的代价很小，可以直接调整。
